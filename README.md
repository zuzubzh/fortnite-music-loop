# Fortnite Music Loop

Une page plein écran qui étire l’image fournie pour remplir exactement toute la fenêtre, quelle que soit sa forme ou sa taille. Le fichier `music.mp3` est lu en arrière-plan et recommence indéfiniment.

## Publication

Le dépôt est publié avec GitHub Pages depuis la branche `main`, à la racine.

## Lecture automatique

La page tente de lancer le son dès son ouverture. Si le navigateur bloque l’autoplay, un clic ou toucher n’importe où sur l’image démarre la musique, sans afficher de bouton ni de commandes de lecteur.
