# Fortnite Music Loop

Une page web plein écran qui étire l’image fournie pour remplir exactement toute la fenêtre, quelle que soit sa forme ou sa taille, et intègre la vidéo YouTube **Ow2eSjJR6TA** en boucle.

## Utilisation

Ouvrir `index.html` ou publier le dépôt avec GitHub Pages. Appuyer sur **Activer la musique** pour démarrer le son. Après activation, le bouton permet de mettre la musique en pause ou de la reprendre.

Le son automatique est bloqué par les navigateurs jusqu’à une interaction. La vidéo est donc lancée en mode muet si l’autoplay est autorisé; un clic active le son.
