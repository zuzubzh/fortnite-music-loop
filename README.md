# Fortnite Music Loop

Une page plein écran qui étire l’image fournie pour remplir exactement toute la fenêtre, quelle que soit sa forme ou sa taille, et tente de lire en boucle la vidéo YouTube **Ow2eSjJR6TA** avec le son dès l’ouverture.

## Publication

Le dépôt est publié avec GitHub Pages depuis la branche `main`, à la racine.

## Autoplay

La page lance la vidéo sans bouton de commande. Les navigateurs peuvent bloquer la lecture automatique avec le son; ce réglage est contrôlé par le navigateur et ne peut pas être contourné par le site.
